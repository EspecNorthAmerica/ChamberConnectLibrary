# What is new in this glclib-py3 branch 

Python 3 library for interfacing with ESPEC North America chambers with ESPEC controllers, GL, P300, P300 (with vibration features), SCP-220, ES-102, Watlow F4T and Watlow F4S/D controllers.

Last date of implementation and updates: January 24, 2026

- Implementation of GL controller library and sample program


## Requirements

Python 3.8.x and above is required for using this distributed library. 

This library has been completely tested under the following Python 3 versions: 

* Python 3.8.x
* Python 3.9.x
* Python 3.10.x
* Python 3.13.x

Recommendations: Use Python 3.11 or higher.
